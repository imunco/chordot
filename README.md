# 弦点 / Chordot

面向中学数学与物理课堂的**教学作图工具**。纸面插画风格，浅色、低饱和、无红色。

## 能做什么

**作图**
点、线段、圆、多边形、函数曲线；拖动顶点或整块图形移动；拖动时实时显示边长。

**几何约束**
水平、竖直、等长、平行、垂直、点在线上、中点、相切（planegcs 求解），约束冲突会标出来。

**动态测量**
选 2 点看距离与 Δx/Δy，选 3 点看角度，选多边形看面积；单位随场景切换（数学 cm，物理 m）。

**函数**
多条曲线同屏自动配色；公式编辑器基于 MathLive，支持 `\frac{x^2}{4}`、`\sqrt{x}`、`\ln(x)`、`2x` 这类课本写法。

**物理**
- 斜面受力：G / N / f，正交分解（`D` 键），力的标尺可调
- 运动仿真：斜面滑块、单摆、弹簧振子、抛体
- 三维斜面受力：楔形 + 物块 + 重力分解虚线 + 倾角弧

**教材实验室**
人教版（2019）高中物理 24 个教材实验，按必修 / 选择性必修与力学 / 电磁学 / 光学 / 热学双维度分类。
每个实验都有可播放的动画演示、实时读数、同步图像和公式代入，另有实验原理、器材与步骤、数据处理、误差与注意四页说明。

**大屏演示**
教材实验可开成独立窗口（投影 / 双屏），默认专注 + 大屏字号；支持滚轮或按钮缩放、拖动画面、放大镜、聚光灯、全屏批注、全屏（F）。
批注可直接画在动画、读数和说明上（I 进入，Esc 只退出批注），实验下拉切换，左侧列表与底部说明可一键收起。

**三维**
正方体、棱柱、棱锥、球、圆柱、圆锥等；拖动旋转、滚轮缩放、正/侧/俯/等轴视角、透视开关。
**看得见的棱实线、被遮挡的棱虚线**，随视角实时变化。

**物理世界（可选）**
把三维场景切换成真实刚体物理：重力、弹性、摩擦、斜面与墙、逐物体变力 `F(t)`。
底部时间轴可暂停、回溯、回到当前。

**机构装配（二维）**
拖部件到画布 → 用弹簧 / 绳 / 杆连起来，就是一台能动的机构：
小球、方块、固定点、轨道、定滑轮、轮（中心轴固定 = 转动副，可加电机力矩）；
弹簧按胡克定律给 `k`、阻尼 `c`，能算 `T = 2π√(m/k)`；杆是刚性连杆（单摆），绳只拉不推、可依次绕过多个滑轮（滑轮组）；
铰链可以把两个部件在任意点铰在一起（端点偏移可调），部件还能约束到轨道上只沿轨道滑。
矢量开关显示速度（m/s）与合力（N），打开「受力分解」就分开画重力 / 弹力 / 支持力 / 摩擦力；
任意部件都能写公式力 `F(x,y,vx,vy,t,m,g)`；支持单个部件复制、子机构复制、成组整组拖动。
预设：弹簧振子、单摆、小车+弹簧、定滑轮、滑轮组、电机轮；可随时拆开连接、拆成独立个体，编辑全进撤销栈。

**符号公式实验室（独立窗口）**
把 `m g k c x v t` 等符号拖到一起拼公式，拼出来的就是作用在小球上的合力：
`-k*x` 是简谐运动，`-k*x-c*v` 是阻尼振动，`m*g` 是重力；实时显示 F、a、v、x、t 与 x–t 图。

**其他**
52+ 模板库（二级分类 / 搜索 / 收藏 / 导入导出 `.chordotpack`）、图形库（平面 10 种 + 立体 11 种，可拖入）、
批注（笔 / 荧光 / 铅笔 / 橡皮；铅笔带纸面颗粒与速度感应；10 快捷色 + 24 色盘 + 自定义取色 + 我的色板 + 最近使用；可一键隐藏）、
符号键盘（可拖动）、命令面板、撤销重做、`.chordot` 存档。

## 开发

```bash
npm install
npm run dev        # Vite + Electron 热更新
npm run build      # 类型检查 + 打包前端到 dist/
npm run preview    # 用构建产物启动
```

## 安装与更新

到 [Releases](https://github.com/imunco/chordot/releases) 下载：

- `Chordot-x.y.z-x64-setup.exe` —— 安装版，**可选安装位置**，自动创建桌面与开始菜单快捷方式
- `Chordot-x.y.z-x64-portable.exe` —— 免安装，双击即用

首次启动会有 8 步引导教学，之后可在「设置 → 个性化 → 引导教学」重新观看。

程序启动时会自动检查更新，发现新版本弹窗提示，可选「忽略本次更新 / 下次提醒我 / 不再提醒」。
下载走 GitHub Releases，内置 12 个国内镜像，**并发测速自动选最快的一个**；
检查频率、下载源、开关都在「设置 → 更新」里。

## 验证

三十六套端到端脚本，全部基于真实 Electron 窗口驱动 UI 并断言结果：

```bash
npm run verify:kernel && npm run verify:construct && npm run verify:file
npm run verify:textbook && npm run verify:bigscreen
# 或逐个跑，清单见 package.json 的 verify:* 脚本
```

每套脚本会打印 `RESULT {...}`，出现 `VERIFY FAILED` 即为失败。

## 目录

```
src/
  components/   界面（画布、左右栏、工具栏、各类面板、教材实验室）
  kernel/       求解内核：几何约束、函数采样、运动仿真、刚体物理
  model/        场景 → 绘制对象的转换、投影、配色
  lab/          教材实验的物理模型与读数
  data/         模板库、图形库、教材实验内容
electron/       主进程、预加载、文件 IPC、验证脚本
```

## 已知边界

- 约束求解基于 planegcs，相切已能做到 0 残差（线固定、圆心落位）
- 「水平」约束只约束方向，不约束长度
- 自定义模板存在 localStorage，换机器会丢
- 三维物理只有地面、斜面与墙，没有绳子/铰链
- 时间轴回放是只读的（看录像），不能从历史帧继续演化

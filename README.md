# 弦点 / Chordot

面向中学数学与物理课堂的**教学作图工具**。纸面插画风格，浅色、低饱和、无红色。

## 能做什么

**0.18.0：纸面 / 液态玻璃双主题**
- **主题切换**：大厅右上角一键切换，设置 → 个性化 里有带预览的主题卡，命令面板也能切；选择写入本机设置，重开、独立窗口、打印之外的所有窗口都跟随。纸面主题保持原样，不引入任何玻璃样式。
- **液态玻璃**：半透明磨砂卡片、内高光与底部暗边、1px 渐变玻璃边框、跟随指针的镜面高光；大厅极光壁纸、点阵和暖冷色光晕都保留。
- **动效**：卡片错峰入场、悬停抬升与高光、主按钮扫光、主题切换时界面轻呼吸、弹层浮入；主题设置新增果冻分段开关，拇指滑动有弹簧回弹、按下会压扁，按钮也有按压回弹。全部走 transform / opacity，支持「减弱动效」与系统 prefers-reduced-motion。
- **性能**：背景极光静态绘制，不再整页逐帧动画；大厅卡片只保留 8px 轻量模糊，侧栏 14px、工具坞 18px；指针高光用 requestAnimationFrame 节流，卡片悬停只过渡 transform。软件渲染稳态实测大厅 60fps、悬停 55fps、编辑器 59fps。
- **控件统一**：分段开关全部换成会滑动的玻璃拇指，开关是带圆钮的玻璃药丸，滑杆有玻璃轨道和会压扁的圆钮；文本框、下拉框统一玻璃底、白色高光和焦点蓝环；按钮按下都有压缩回弹。全部仅玻璃主题生效，纸面主题保持不变。
- **教材实验室升级**：原先把 14 个模型错落到实验舞台、部分模型共用同一个「人船」演示；现在 26 个模型全部使用 model 舞台和各自的物理公式，补齐碰撞 / 单摆 / 弹簧振子 / 平抛 / 竖直圆周 / 单杆 / 变压器 / 动态电路 / 机械能等 9 类新场景；画面加入渐变材质、柔光投影、运动轨迹、能量条和实时 HUD，不再是纯线条示意图。每个模型都配有可用的参数滑杆和实时图像。

**0.17.0：全局演示工具 + 高中物理模型专题**
- **聚光灯 / 放大镜全局可用**：不再只属于教材实验室——主编辑器在任何模式（数学 / 物理 / 三维 / 机构）都能从「更多」菜单或命令面板打开，聚光灯跟随指针压暗四周，放大镜跟随指针实时放大画布；Esc 关闭。
- **教材实验室新增「模型」专题（26 个）**：人船、板块、传送带、追及相遇、连接体、双星、卫星变轨、带电粒子在磁场、双杆导轨、斜面、交变电流有效值、能级跃迁、光电效应、回旋加速器、子弹打木块、爆炸、弹性 / 完全非弹性碰撞、单摆、弹簧振子、平抛 / 类平抛、竖直圆周临界、电磁感应单杆、变压器与远距离输电、电路动态分析、机械能守恒 / 功能关系。每个模型都有模型特征、核心方程、解题步骤、易错点和可调参数的演示台。
- 教材实验室列表、搜索、上一个 / 下一个都同时覆盖「实验」与「模型」；模型按「模型」分册单独筛选。

**0.16.0：把「课件」当文件管起来**
- **每日一言**：大厅显示 Hitokoto 每日一句（3 秒超时 + 本地句子兜底，断网也能用），可换一句。
- **自动保存 / 崩溃恢复**：编辑器里有改动就定时写快照；异常退出后重开，大厅出现「恢复未保存的课件」。
- **版本历史 / 课件库**：每次覆盖保存前的旧版本自动留档（每份最多 20 份，可随时恢复）；「保存到课件库」把课件收进本机课件库，大厅「我的课件」直接打开。
- **文件关联 / 拖拽打开**：安装包注册 `.chordot` 双击打开；把课件拖进窗口也能打开。
- **课件元信息**：新建时可填学段、章节、备注；保存进文件，大厅最近课件显示标题/章节，不再只有文件名。
- **演示者模式**：全屏画布 + 计时器 + 镜头书签（PageUp/PageDown 兼容翻页笔）+「投影增强」加粗高对比，Esc 退出。
- **PDF 讲义**：当前画面 + 标题/学段章节排成 A4 横向讲义，原生 `printToPDF` 导出。
- **窗口独立**：教材实验室、模板库、符号实验室都能开成独立窗口，主窗口继续画图；教材窗口不再强制同步主窗口。
- **机构物理保真**：自定义库仑摩擦（静摩擦/滑动摩擦、冰面低摩擦），支持力 N 与摩擦力 f 来自同一次接触结算，受力分解读数一致。
- **符号实验室**：常量可改并记住、内置公式库 + 自定义公式、求值结果可绑定弹簧 k / 阻尼 c / 部件质量。
- **三维贴图 / 展开图**：木纹/纸纹/金属/网格位图贴图与自定义图片（UV 逐面），多面体可摊平成带棱长标注的展开图。
- **本地错误日志**：主进程与渲染层异常写到数据目录 `logs/`，离线也能排查。

**启动大厅（0.15.0）**
每次进入程序先看到大厅：数学 / 物理 / 运动仿真 / 三维 / 机构装配 / 教材实验室 / 符号实验室 / 模板库 八个模式一键进入；
「新建课件」会先让你设属性（名称、学科、初始画布、网格密度、坐标刻度、角度单位、触控大按钮），并带画布预览；
「最近课件」「上次打开」「当前正在编辑」从大厅直接继续；标题栏与菜单随时可以「返回大厅」。
可以在 设置 → 通用 → 启动页 关掉（直接进编辑器），也支持 `?lobby=0`。

**作图**
点、线段、圆、多边形、函数曲线；拖动顶点或整块图形移动；拖动时实时显示边长。

**几何约束**
水平、竖直、等长、平行、垂直、点在线上、中点、相切（planegcs 求解），约束冲突会标出来。

**动态测量**
选 2 点看距离与 Δx/Δy，选 3 点看角度，选多边形看面积；单位随场景切换（数学 cm，物理 m）。

**函数**
多条曲线同屏自动配色；公式编辑器基于 MathLive，支持 `\frac{x^2}{4}`、`\sqrt{x}`、`\ln(x)`、`2x` 这类课本写法。

**物理**
- 斜面受力：G / N / f，正交分解（`D` 键），力的标尺可调
- 运动仿真：斜面滑块、单摆、弹簧振子、抛体
- 三维斜面受力：楔形 + 物块 + 重力分解虚线 + 倾角弧

**教材实验室**
人教版（2019）高中物理 24 个教材实验 + 26 个高中常用模型，按必修 / 选择性必修与力学 / 电磁学 / 光学 / 热学双维度分类。
每个实验都有可播放的动画演示、实时读数、同步图像和公式代入，另有实验原理、器材与步骤、数据处理、误差与注意四页说明。

**大屏演示**
教材实验可开成独立窗口（投影 / 双屏），默认专注 + 大屏字号；支持滚轮或按钮缩放、拖动画面、放大镜、聚光灯、全屏批注、全屏（F）。
批注可直接画在动画、读数和说明上（I 进入，Esc 只退出批注），实验下拉切换，左侧列表与底部说明可一键收起。

**三维**
正方体、棱柱、棱锥、球、圆柱、圆锥等；拖动旋转、滚轮缩放、正/侧/俯/等轴视角、透视开关。
**看得见的棱实线、被遮挡的棱虚线**，随视角实时变化。

**物理世界（可选）**
把三维场景切换成真实刚体物理：重力、弹性、摩擦、斜面与墙、逐物体变力 `F(t)`。
底部时间轴可暂停、回溯、回到当前。

**机构装配（二维 · 物理模式）**
拖部件到画布 → 用连接 / 约束 / 传动串起来，就是一台真能动、能测的机构：

- **23 种部件**：小球 / 方块 / 小车 / 木板 / 圆盘 / 圆环 / 斜面 / 砝码；固定点 / 固定座 / 挡板 / 直轨道 / 圆弧轨道；定滑轮 / 动滑轮 / 齿轮 / 齿条 / 轮 / 飞轮 / 传送带；推力器 / 磁铁 / 引力源。
- **10 种连接**：弹簧（`F=k·Δx`，可算 `T=2π√(m/k)`）、阻尼器、绳（只拉不推，可依次绕过多个定滑轮 / 动滑轮）、刚性杆、铰链（任意点铰接 + 角度限位）、焊接（锁死相对位姿）、皮带、齿轮啮合（按半径比反向外传动）、齿轮齿条、液压 / 气动活塞。
- **专业建模**：网格吸附、角度吸附、Shift 多选、对齐 / 分布、旋转、成组、子机构复制、锁定、材质预设（钢 / 木 / 橡胶 / 塑料 / 冰面，含摩擦与恢复系数）、自重比例（0 = 失重）、电机力矩、推力、磁极、传送带速度。
- **看得见的物理**：矢量开关显示速度（m/s）与合力（N）；「受力分解」分开画重力 / 弹力 / 支持力 / 摩擦力；两点测距；轨迹；实时读数（动能 / 重力势能 / 弹性势能 / 总机械能 / 动量）。
- **18 个预设**：弹簧振子、水平弹簧振子、单摆、小车+弹簧、杠杆、斜面滑块、圆弧轨道、定滑轮、滑轮组、动滑轮、电机轮、齿轮传动、带传动、曲柄滑块、液压缸、火箭推力、磁铁、空白装配台。
- 编辑 / 真实双模式：编辑时物理暂停、摆零件；真实时按物理规律运行、按住部件拖动就是施力。任意部件都能写公式力 `F(x,y,vx,vy,t,m,g)`，编辑全进撤销栈、可存成 `.chordot`。

**符号公式实验室（独立窗口）**
把 `m g k c x v t` 等符号拖到一起拼公式，拼出来的就是作用在小球上的合力：
`-k*x` 是简谐运动，`-k*x-c*v` 是阻尼振动，`m*g` 是重力；实时显示 F、a、v、x、t 与 x–t 图。

**其他**
52+ 模板库（二级分类 / 搜索 / 收藏 / 导入导出 `.chordotpack`）、图形库（平面 10 种 + 立体 11 种，可拖入）、
批注（笔 / 荧光 / 铅笔 / 橡皮；铅笔带纸面颗粒与速度感应；10 快捷色 + 24 色盘 + 自定义取色 + 我的色板 + 最近使用；可一键隐藏）、
符号键盘（可拖动）、命令面板、撤销重做、`.chordot` 存档。

## 开发

```bash
npm install
npm run dev        # Vite + Electron 热更新
npm run build      # 类型检查 + 打包前端到 dist/
npm run preview    # 用构建产物启动
```

## 安装与更新

到 [Releases](https://github.com/imunco/chordot/releases) 下载：

- `Chordot-x.y.z-x64-setup.exe` —— 安装版，**可选安装位置**，自动创建桌面与开始菜单快捷方式
- `Chordot-x.y.z-x64-portable.exe` —— 免安装，双击即用

首次启动会有 8 步引导教学，之后可在「设置 → 个性化 → 引导教学」重新观看。

程序启动时会自动检查更新，发现新版本弹窗提示，可选「忽略本次更新 / 下次提醒我 / 不再提醒」。
下载走 GitHub Releases，内置 12 个国内镜像，**并发测速自动选最快的一个**；
检查频率、下载源、开关都在「设置 → 更新」里。

npm run verify:textbook && npm run verify:bigscreen && npm run verify:mech

## 已知边界

- 约束求解基于 planegcs，相切已能做到 0 残差（线固定、圆心落位）
- 「水平」约束只约束方向，不约束长度
- 自定义模板存在 localStorage，换机器会丢
- 三维物理只有地面、斜面与墙，没有绳子/铰链
- 时间轴回放是只读的（看录像），不能从历史帧继续演化

# 弦点 / Chordot

面向中学数学与物理课堂的**教学作图工具**。纸面插画风格，浅色、低饱和、无红色。

## 能做什么

**作图**
点、线段、圆、多边形、函数曲线；拖动顶点或整块图形移动；拖动时实时显示边长。

**几何约束**
水平、竖直、等长、平行、垂直、点在线上、中点、相切（planegcs 求解），约束冲突会标出来。

**动态测量**
选 2 点看距离与 Δx/Δy，选 3 点看角度，选多边形看面积；单位随场景切换（数学 cm，物理 m）。

**函数**
多条曲线同屏自动配色；公式编辑器基于 MathLive，支持 `\frac{x^2}{4}`、`\sqrt{x}`、`\ln(x)`、`2x` 这类课本写法。

**物理**
- 斜面受力：G / N / f，正交分解（`D` 键），力的标尺可调
- 运动仿真：斜面滑块、单摆、弹簧振子、抛体
- 三维斜面受力：楔形 + 物块 + 重力分解虚线 + 倾角弧

**三维**
正方体、棱柱、棱锥、球、圆柱、圆锥等；拖动旋转、滚轮缩放、正/侧/俯/等轴视角、透视开关。
**看得见的棱实线、被遮挡的棱虚线**，随视角实时变化。

**物理世界（可选）**
把三维场景切换成真实刚体物理：重力、弹性、摩擦、斜面与墙、逐物体变力 `F(t)`。
底部时间轴可暂停、回溯、回到当前。

**其他**
52+ 模板库（二级分类 / 搜索 / 收藏 / 导入导出 `.chordotpack`）、图形库（平面 10 种 + 立体 11 种，可拖入）、
画笔批注（二维跟随画布，三维固定在屏幕）、符号键盘（可拖动）、命令面板、撤销重做、`.chordot` 存档。

## 开发

```bash
npm install
npm run dev        # Vite + Electron 热更新
npm run build      # 类型检查 + 打包前端到 dist/
npm run preview    # 用构建产物启动
```

## 验证

二十四套端到端脚本，全部基于真实 Electron 窗口驱动 UI 并断言结果：

```bash
npm run verify:kernel && npm run verify:construct && npm run verify:file
# 或逐个跑，清单见 package.json 的 verify:* 脚本
```

每套脚本会打印 `RESULT {...}`，出现 `VERIFY FAILED` 即为失败。

## 打包分发

```bash
npm i -D electron-builder   # 首次
npm run dist                # 产出 release/ 下的安装包与免安装版
```

## 目录

```
src/
  components/   界面（画布、左右栏、工具栏、各类面板）
  kernel/       求解内核：几何约束、函数采样、运动仿真、刚体物理
  model/        场景 → 绘制对象的转换、投影、配色
  data/         模板库、图形库
electron/       主进程、预加载、文件 IPC、验证脚本
```

## 已知边界

- 约束求解基于 planegcs，相切约束有约 0.07 单位残差
- 「水平」约束只约束方向，不约束长度
- 自定义模板存在 localStorage，换机器会丢
- 三维物理只有地面、斜面与墙，没有绳子/铰链
- 时间轴回放是只读的（看录像），不能从历史帧继续演化
